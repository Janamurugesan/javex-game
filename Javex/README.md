# JAVEX – Game Development Company Landing Page

A modern, premium, visually stunning AAA-grade landing page for **JAVEX**, a high-end game development company and startup focused on developing innovative, immersive, and unforgettable gaming experiences.

---

## 🎮 Live Preview & Quick Start

To view the landing page locally:

```bash
# Using Python built-in HTTP server:
python -m http.server 8088

# Open in browser:
http://localhost:8088
```

Or simply double-click and open `index.html` in any modern web browser.

## 🛠️ Tech Stack & Architecture

- **Markup:** Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Styling:** Modular CSS3 with CSS Custom Properties, Flexbox, Grid, Glassmorphism (`backdrop-filter`), and keyframe animations.
- **Interactions:** Vanilla JavaScript (ES6+), zero external dependencies or heavy frameworks.
- **Audio:** Web Audio API sound synthesizer (no external audio assets required).
- **Accessibility:** Reduced motion query (`prefers-reduced-motion`), ARIA attributes, semantic structure, high color contrast, and keyboard navigation.
